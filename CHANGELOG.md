# Changelog

All notable changes to RenderVet are documented here.

## [0.1.0] - 2026-08-10

### Added

- Versioned TOML batch contracts.
- Expected count and numbered sequence validation.
- Native PNG, JPEG, GIF, WebP, and BMP structure/dimension probes.
- Optional audio/video metadata inspection through `ffprobe`.
- File size, extension, duration, audio-stream, freshness, and exact-duplicate checks.
- Offline HTML report, JSON report, and retry manifest.
- Deterministic `rendervet demo` failure fixture.
- Local-only and read-only safety boundaries, including symlink rejection.
